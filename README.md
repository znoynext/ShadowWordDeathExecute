# Shadow Word: Death Execute

Минимальный аддон для Priest в WoW Retail. Иконка **Shadow Word: Death** появляется только тогда, когда текущая вражеская живая цель находится на 20% здоровья или ниже, а способность можно применить прямо сейчас.

Команда `/swd` открывает небольшое окно настройки:

- `Закрепить` — запрещает перемещение индикатора.
- `Тест` — показывает иконку для настройки; перемещать её можно только в этом режиме и при снятом закреплении.
- Размер — меняет размер иконки.
- `Сбросить` — возвращает позицию в центр и размер 48 px.

Позиция, размер и состояние закрепления сохраняются между игровыми сессиями. После закрытия окна тестовый режим автоматически выключается.
