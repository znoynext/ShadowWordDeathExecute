# Shadow Word: Death Execute

Минимальный аддон для Priest в WoW Retail. Иконка **Shadow Word: Death** появляется только тогда, когда текущая вражеская цель находится на 20% здоровья или ниже и способность можно применить прямо сейчас. Если иконка не показана — нажимать способность пока не нужно.

Команда `/swd` открывает небольшое окно, где можно закрепить индикатор, включить тестовый показ и выбрать его размер. Позиция, размер и состояние закрепления сохраняются между игровыми сессиями.
