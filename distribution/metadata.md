## Project name

Shadow Word: Death Execute

## One-line description

A lightweight Shadow Word: Death execute indicator for World of Warcraft Retail.

## Short description

Shadow Word: Death Execute is a focused Priest addon for World of Warcraft Retail that shows an icon when a hostile living target reaches the 20% execute threshold and Shadow Word: Death is available.

## Long description

This event-driven addon provides a compact, movable, and resizable Shadow Word: Death execute indicator. It appears only in combat against a hostile living target at 20% health or lower, respects Shadow Word: Death's own cooldown, and does not disappear for the global cooldown alone. An optional Blizzard glow and compact `/swd` settings are included. English and Russian are supported. No external runtime libraries are required.

## Feature list

- Combat-only execute indicator for Shadow Word: Death.
- Hostile living target and 20% execute threshold checks.
- Shadow Word: Death cooldown and charge-aware availability.
- Global cooldown does not hide an otherwise ready indicator.
- Optional Blizzard glow.
- Movable and resizable icon with compact `/swd` settings.
- English and Russian localization.
- Event-driven operation with no external runtime libraries.
