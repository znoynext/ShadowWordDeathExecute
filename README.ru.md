# Shadow Word: Death Execute

[English](README.md) | [Русский](README.ru.md)

Лёгкий аддон для Priest в World of Warcraft Retail: он показывает execute-индикатор Shadow Word: Death, когда враждебная цель готова к добиванию.

## Возможности

- Показывает Shadow Word: Death в диапазоне добивания.
- Работает только в бою и требует враждебную живую цель.
- Использует порог добивания 20%.
- Учитывает собственный cooldown Shadow Word: Death.
- Не скрывает индикатор только из-за global cooldown.
- Оставляет индикатор доступным, если одну charge ещё можно использовать, пока другая восстанавливается.
- Поддерживает необязательное Blizzard-свечение и компактные настройки `/swd`.
- Поддерживает ручные поля Position X/Y и отдельные Size X/Y для квадратного или прямоугольного индикатора.
- Старый единый сохранённый размер автоматически переносится в одинаковые значения ширины и высоты.
- Локализован на английский и русский.
- Работает через события и не использует внешние runtime-библиотеки.

## Установка

1. Скачайте release ZIP.
2. Извлеките папку `ShadowWordDeathExecute`.
3. Поместите её в `World of Warcraft/_retail_/Interface/AddOns`.
4. Перезапустите World of Warcraft или выполните `/reload`.

## Использование

Команда `/swd` открывает компактное окно настроек:

- **Закрепить** запрещает перемещать индикатор.
- **Тест** показывает иконку для настройки положения.
- **Position X/Y** вручную задают положение индикатора.
- **Size X/Y** вручную задают ширину и высоту иконки; поддерживаются квадратный и прямоугольный размеры.
- **Свечение** включает необязательное Blizzard-свечение.
- **Сбросить** возвращает положение и размер по умолчанию.

## Поведение execute-индикатора

Выше 20% здоровья иконка визуально скрыта. При 20% здоровья или ниже она видна, когда Shadow Word: Death доступен. Сам global cooldown её не скрывает, а собственный cooldown Shadow Word: Death скрывает. Доступная charge остаётся usable, пока другая charge восстанавливается.

## Совместимость

Аддон предназначен для World of Warcraft Retail и Priest, использующих Shadow Word: Death. Поддерживаемая версия Interface задана в TOC аддона (сейчас `120007`).

## Устранение неполадок

- Убедитесь, что аддон включён.
- Выполните `/reload`.
- Проверьте, что установлена актуальная версия аддона.
- Включите Lua errors и приложите stack trace к сообщению.
- Повторите проверку с отключёнными другими аддонами.
- Если проблема осталась, [создайте GitHub issue](https://github.com/znoynext/ShadowWordDeathExecute/issues).
